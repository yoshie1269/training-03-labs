# httpd + Tomcat 連携 手順書（AJP版・修正版）

## 概要

### この構成でしていること

Apache(httpd) をフロントに配置し、  
Tomcatへ **AJPプロトコル（8009）** で接続する

---

### 構成
```bash
ブラウザ  
↓  
httpd（80）  
↓  
AJP（8009）  
↓  
Tomcat  
```

---

## 前提条件

### 環境

- Amazon Linux  
- root権限あり  
- httpd / Tomcat インストール済み  
- 80/TCP開放  
- 8009は外部公開しない  

---

## 7 AJP Connector設定

### この工程でしていること

TomcatでAJP通信を有効化

---

### 編集ファイル

/usr/local/apache-tomcat-9.0.115/conf/server.xml  

---

### 追記（Service内）
```bash
<Connector protocol="AJP/1.3"
           address="127.0.0.1"
           port="8009"
           secretRequired="true"
           secret="ajpsecret123"
           redirectPort="8443" />
```

---

### 設定の意味

- port 8009：AJP通信ポート  
- address 127.0.0.1：ローカル限定  
- secret：認証キー  

---

### 確認方法
```bash
cat server.xml  
```

---

### OKの目安

- Connectorが追加されている

## 10 httpd設定

### この工程でしていること

httpd → Tomcat(AJP)転送設定

---

### 設定ファイル
```bash
/etc/httpd/conf.d/tomcat-ajp.conf  
```

---

### 設定内容
```bash
ProxyRequests Off  

ProxyPass        /app/ ajp://127.0.0.1:8009/app/ secret=ajpsecret123  
ProxyPassReverse /app/ ajp://127.0.0.1:8009/app/ secret=ajpsecret123  

<Location /app/>  
    Require all granted  
</Location>  
```

---

### 設定の意味

- ProxyPass：転送設定  
- ajp://：AJPプロトコル使用  
- secret：Tomcatと一致必須  

---

### 確認方法
```bash
cat /etc/httpd/conf.d/tomcat-ajp.conf  
```

---

### OKの目安

- 設定が正しく記述されている
