# httpd 演習 手順書（DNSなし版 / Mac対応）

## 概要

### この演習でしていること

Apache(httpd) の VirtualHost を使い  
1台のサーバで複数サイトを公開する

DNSは使用せず、Macのhostsファイルで名前解決する

---

### 構成

- site1.local → /var/www/site1  
- site2.local → /var/www/site2  

---

## 前提条件

### 環境

- Amazon Linux（EC2）  
- Mac使用  
- 80/TCP開放済み  
- root権限あり  

---

## EC2側作業

## 1 httpdインストール・起動

### この工程でしていること

Webサーバを導入し起動する

---

### コマンド
```bash
dnf install -y httpd  
```
```bash
systemctl start httpd  
```
```bash
systemctl enable httpd  
```

---

### 確認方法
```bash
systemctl status httpd  
```
```bash
ss -ltnp | grep :80  
```

---

### OKの目安

- active (running)

## 4 VirtualHost設定

### この工程でしていること

ドメインごとに表示内容を分ける

---

### 設定ファイル

/etc/httpd/conf.d/vhost.conf  

---

### 設定の意味

- ServerName：アクセスされたホスト名で振り分け  
- DocumentRoot：表示するディレクトリ  
- Directory：アクセス許可設定  

---

### 確認方法
```bash
cat /etc/httpd/conf.d/vhost.conf  
```

---

### OKの目安

- 設定が正しく記述されている  

---

## トラブル対処

## 403 Forbidden

### 原因

- Directory設定不足  
- 権限不足  

---

### 確認
```bash
ls -ld /var/www/site1 /var/www/site2  
```
```bash
cat /etc/httpd/conf.d/vhost.conf  
```

---

### 対処

- Require all granted を設定  

---

## 404 Not Found

### 原因

- DocumentRootミス  
- index.htmlなし  

---

### 確認
```bash
ls -l /var/www/site1/index.html  
```
```bash
ls -l /var/www/site2/index.html  
```

---

## 同じページが表示される

### 原因

- hosts設定ミス  
- ServerName不一致  

---

### 確認
```bash
cat /etc/hosts  
```
```bash
curl -H "Host: site1.local" http://127.0.0.1/  
```

---

## ブラウザで開けない

### 原因

- SG未開放  
- httpd停止  

---

### 確認
```bash
systemctl status httpd  
```
```bash
ss -ltnp | grep :80  
```

---

- VirtualHostで出し分け成功
