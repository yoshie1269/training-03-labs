# nginx リバースプロキシ 手順書（Tomcat連携）

## 概要

### この構成でしていること

nginx をフロントに配置し、  
Tomcat（バックエンド）へリクエストを転送する

---

### 構成
```bash
ブラウザ  
↓  
nginx（80）  
↓  
Tomcat（8080）  
```

---

## 4 リバースプロキシ設定

### この工程でしていること

nginx → Tomcat へ転送設定

---

### 編集ファイル

/etc/nginx/conf.d/tomcat.conf  

---

### 設定内容
```bash
server {  
    listen 80;  
    server_name _;  

    location /app/ {  
        proxy_pass http://127.0.0.1:8080/app/;  

        proxy_set_header Host $host;  
        proxy_set_header X-Real-IP $remote_addr;  
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;  
        proxy_set_header X-Forwarded-Proto $scheme;  
    }  

    location / {  
        root /usr/share/nginx/html;  
        index index.html;  
    }  
}  
```

---

### 設定の意味

#### proxy_pass

nginx → Tomcatへリクエスト転送  

---

#### proxy_set_header

クライアント情報をTomcatへ引き継ぐ  

- Host：アクセスドメイン  
- X-Real-IP：クライアントIP  
- X-Forwarded-For：経由IP  
- X-Forwarded-Proto：http/https  

---

### 確認方法
```bash
cat /etc/nginx/conf.d/tomcat.conf  
```

---

### OKの目安

- 設定が正しく記述されている

## トラブルシューティング

### 502 Bad Gateway

#### 原因

- Tomcat停止  
- ポート違い  

#### 確認
```bash
systemctl status tomcat  
```
```bash
ss -ltnp | grep 8080  
```

---

### 404 Not Found

#### 原因

- proxy_passのパスミス  

#### 確認
```bash
curl http://127.0.0.1:8080/app/  
```

---

### 403 Forbidden

#### 原因

- 権限不足  
- SELinux

