# nginx 演習 手順書（競合なし版：SELinux除外）

## 概要

### この演習でしていること

- nginxで複数の公開設定を1つのserverで管理
- root変更、リダイレクト、IP制御を実装
- server{}競合を防ぐ設計を学ぶ

---

## 重要ポイント

- server {} は1つのみ作成  
- 機能は location で追加  
- conf.d/practice.conf に集約

## server設定作成

### 設定ファイル
/etc/nginx/conf.d/practice.conf  

### 設定内容
```bash
server {
    listen 80;
    server_name _;

    root /usr/share/nginx/html;
    index index.html index.htm;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

---

### 設定の意味

- root：公開ディレクトリ  
- try_files：存在チェック  

---

```bash
mv /etc/nginx/conf.d/default.conf /etc/nginx/conf.d/default.conf.back 2>/dev/null
```

# web2：root変更（/home/saba）

## ディレクトリ作成


---

## HTML作成

### コマンド
```bash

```

---

## 設定変更

### 編集ファイル
/etc/nginx/conf.d/practice.conf  

---

### 設定内容（server内）
```bash
server {
    listen 80;
    server_name _;

    root /home/saba;
    index index.html index.htm;

    location /yakiniku/ {
        root /usr/share/nginx/html;
        try_files $uri $uri/ =404;
    }

    location / {
        try_files $uri $uri/ =404;
    }
}
```

---

### 設定の意味

- root変更：/home/saba を基準にする  
- location /yakiniku：例外的に元ディレクトリ使用  

---

# web4：IP制御

## ディレクトリ作成
```bash
mkdir -p /usr/share/nginx/html/apple  
```

---

## HTML作成
```bash
vi /usr/share/nginx/html/apple/ringo  
```
---

## 設定追加

### 編集ファイル
/etc/nginx/conf.d/practice.conf  

---

### 追記（server内）
```bash
location /apple/ {
    allow 自分のPrivateIP;
    deny all;
    root /usr/share/nginx/html;
    try_files $uri $uri/ =404;
}
```

---

### 設定の意味

- allow：許可IP  
- deny all：その他拒否  

---

## 反映

```bash
nginx -t 
```
```bash 
systemctl restart nginx  
```
